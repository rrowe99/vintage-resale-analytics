# Vintage Resale Business - Data Analysis (2021-2025)

Analysis of five years of data from my vintage clothing resale business, which sells across eBay, Depop, Grailed, and in person flea markets in New England.

**Tech Stack:** Python (pandas, pdfplumber, matplotlib) · PostgreSQL · Jupyter
